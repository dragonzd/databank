# DataBank 数据银行系统

## 项目结构

```
Data-Bank/
├── 需求文档/
│   └── 数据银行商业计划书.md          # 原始商业计划书 (Pandoc 转换)
├── 设计文档/
│   ├── 系统平台建设方案/                # 三平台架构完整设计 (HTML 报告)
│   │   └── data-bank-platform-design.html
│   └── 实施落地方案/                    # 分阶段实施与里程碑 (HTML 报告)
│       └── data-bank-implementation-plan.html
├── 源码/
│   ├── 用户应用平台/                    # 面向数据所有方 + 鉴权方 (青 #00d4ff)
│   │   ├── index.html                  #   Port 8081
│   │   └── echarts.min.js
│   ├── 银行业务平台/                    # 面向银行业务人员 (金 #f59e0b)
│   │   ├── index.html                  #   Port 8082
│   │   └── echarts.min.js
│   └── 数据交易平台/                    # 面向数据使用者 (绿 #34d399)
│       ├── index.html                  #   Port 8083
│       └── echarts.min.js
└── 输出物/
    ├── 01-产品分析.md                  # 产品经理 Alex 分析输出
    ├── 02-技术设计.md                  # 软件架构师设计输出
    └── 03-任务拆解.md                  # 高级 PM 拆解输出
```

## 三平台架构

| 平台        | 用户          | 核心功能                                         | 主题色             |
|------------|---------------|--------------------------------------------------|-------------------|
| 用户应用平台 | 数据所有方+鉴权方 | 数据存款/理财/贷款、联合账户、鉴权方自服务          | `#00d4ff` 青       |
| 银行业务平台 | 银行业务人员    | 产品配置、鉴权方准入准出、协议规则、驾驶舱、收益分析 | `#f59e0b` 金       |
| 数据交易平台 | 数据使用者     | 数据/模型市场、Token购买充值、会员订阅、交易记录    | `#34d399` 绿       |

## 快速启动

```bash
# 用户应用平台
cd 源码\用户应用平台 && python -m http.server 8081

# 银行业务平台
cd 源码\银行业务平台 && python -m http.server 8082

# 数据交易平台
cd 源码\数据交易平台 && python -m http.server 8083
```
